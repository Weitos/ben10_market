# CLAUDE.md — Системный контекст разработки Ben 10 Market
Данный файл является главным контрактом для ИИ-агента (OpenCode / Claude Code / Cursor). Разработка ведется строго пошагово. Не переходить к следующему шагу без валидации предыдущего и запуска тестов.

## Архитектура проекта
- data/mock_data.json — Локальный бэкап-буфер данных (исходный JSON).
- src/main.py — Главная точка входа для асинхронного запуска всей экосистемы.
- src/base/ — Бэкэнд-слой (Бизнес-логика, API, Таблицы):
  - data_provider.py — Модуль запросов к AliExpress API и логика переключения на JSON.
  - analytics.py — Обработка массивов данных через Pandas, расчет маржи и выявление ТОП-позиций.
  - sheets_client.py — Взаимодействие с gspread, заливка таблиц и условное форматирование.
- src/tele/ — Фронтенд-слой (Интерфейс Telegram-бота):
  - bot.py — Конфигурация и инициализация Bot и Dispatcher (Aiogram 3.x).
  - handlers.py — Асинхронные обработчики команд, текстовых запросов и инлайн-событий.
  - kb.py — Модуль сборки пользовательского интерфейса (кнопки, меню).

### Архитектурные правила:
1. **Язык:** Python 3.11+.
2. **Стиль кода:** PEP 8, строгая типизация (Type Hinting), асинхронность для сетевых запросов.
3. **Отказоустойчивость:** Любой запрос к API (AliExpress, Google Sheets, Telegram) должен быть обернут в блоки обработки ошибок. При ошибках сети применять экспоненциальную задержку (повтор через 2, 4, 8, 16 секунд).
4. **Логирование:** Использовать модуль `logging`. Писать логи уровня `INFO` и `ERROR` в файл `app.log`.

## 🗺️ Пошаговый план реализации (10 Шагов для ИИ)

### ✅ Шаг 1: Инициализация проекта и Локальный Дата-слой
- Настроить базовую структуру проекта, менеджер зависимостей (Requirements/Poetry) и логирование в `app.log`.
- Внутри модуля `src/base/data_provider.py` реализовать чтение входящего файла `mock_data.json` из папки data (схема: id, name, price, cost_price, commission_pct, barcode). Обеспечить валидацию полей через Pydantic.

### ✅ Шаг 2: Модуль интеграции AliExpress API
- Внутри `src/base/data_provider.py` реализовать асинхронную функцию запроса к API AliExpress по ключу `"Ben 10"`.
- Написать логику фоллбэка: если API возвращает ошибку или таймаут, функция должна залогировать это и прозрачно вернуть данные из локального `data/mock_data.json`.

### ✅ Шаг 3: Реализация Экспоненциальной Задержки (Retry Logic)
- В `src/base/data_provider.py` написать кастомный асинхронный декоратор @retry_with_backoff.
- Параметры: max_retries=5, base_delay=2. Декоратор должен увеличивать задержку экспоненциально при сетевых ошибках ConnectionError или таймаутах.

### ✅ Шаг 4: Аналитический движок на Pandas
- Внутри модуля `src/base/analytics.py` реализовать функцию `process_market_data(data)`.
- Она должна преобразовывать входящие данные в Pandas DataFrame и рассчитывать:
  - `Чистая маржа (руб)` = Цена (`price`) - Себестоимость (`cost_price`) - (Цена * Процент комиссии (`commission_pct`)).
  - Сортировка по маржинальности/объему для выявления ТОП-3 лучших и ТОП-3 худших товаров.

### ✅ Шаг 5: Интеграция Google Sheets API (gspread) — Базовая выгрузка
- Внутри модуля `src/base/sheets_client.py` настроить аутентификацию через Service Account JSON.
- Реализовать очистку листа и заливку обновленного DataFrame из Pandas в Google Таблицу. Создать понятную структуру колонок для бизнеса.

### ✅ Шаг 6: Условное форматирование в Google Sheets (gspread-formatting)
- Расширить `src/base/sheets_client.py`. Добавить логику форматирования ячеек.
- Скрипт должен находить строки ТОП-3 лучших товаров и красить их бэкграунд в мягкий зеленый цвет (`#E2EFDA`), а ТОП-3 худших — в мягкий красный цвет (`#FCE4D6`).

### ✅ Шаг 7: Инициализация Telegram-бота на Aiogram 3.x
- Внутри модуля `src/tele/bot.py` и точки входа `src/main.py`настроить базовый запуск бота, диспетчера и чтение токенов из `.env`.
- Написать логику логирования входящих команд от пользователей.

### ✅ Шаг 8: Разработка UI/UX Telegram-бота (Кнопки и Меню)
- Внутри модуля `src/tele/kb.py` создать клавиатуры (Reply/Inline) с кнопками: 📊 "Получить актуальный отчет", ⚙️ "Настройки парсинга", 🔄 "Синхронизировать БД".
- Внутри модуля `src/tele/handlers.py` реализовать стейт-машину (FSM) для изменения настроек (например, переключение источника API/JSON вручную).

### ✅ Шаг 9: Связка Слоев (Интеграция Бот -> Бэкэнд -> Таблицы)
- В `src/tele/handlers.py` написать хэндлер для кнопки "Получить актуальный отчет". 
- Бот запускает цепочку: Сбор данных -> Анализ в Pandas -> Экспорт и подкраска в Google Sheets -> Возврат пользователю ссылки на таблицу и текстового резюме (Топ товаров прямо в чат).
