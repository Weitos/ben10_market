# Ben 10 Market (E-commerce Automation & Analytics)

Автоматизированная система мониторинга, анализа маржинальности и менеджмента товарных позиций мерча "Бен 10". Скрипт агрегирует данные из внешних источников, производит математический анализ волатильности цен и выгручает отчётность в локальную БД (SQLite) и Excel-файлы с цветовой разметкой, управляясь через интерфейс Telegram-бота.

## 🚀 Архитектурный Стек
- **Frontend / Control Layer:** `Python (Aiogram 3.x)` — асинхронный Telegram-бот с интерактивным интерфейсом (кнопки, клавиатуры).
- **Business Logic Layer:** `Python (Pandas)` — векторизованная обработка массивов данных, расчет финансовой аналитики и маржинальности.
- **Data & Storage Layer:** `SQLite (SQLAlchemy ORM)` — структурированное хранение продуктов и связанных финансовых метрик.
- **Presentation / Export Layer:** `Openpyxl` — генерация кастомных Excel-дашбордов с автоматическим выравниванием колонок и условным форматированием.
- **Data Sources:** Гибридный провайдер (`AliExpress API` с отказоустойчивым фоллбэком на локальный `mock_data.json`).

## ✅ Реализованный Функционал
1. **Гибридный сбор данных:** Приоритетный асинхронный парсинг товаров через API AliExpress по запросу `"Ben 10"`. При лимитах или сетевых ошибках система незаметно для пользователя переключается на локальный валидируемый JSON-буфер.
2. **Бизнес-аналитика (Pandas):** 
   - Расчет чистой маржи в рублях с учетом цены, себестоимости и комиссии площадки (`commission_pct`).
   - Расчет процента маржинальности (`margin_pct`) с автоматической сортировкой позиций по прибыльности.
3. **ORM Хранилище (SQLite + SQLAlchemy):** Данные распределяются по двум связанным таблицам (`products` и `financial_metrics`) с каскадным удалением и обновлением записей.
4. **Умные Excel-Отчеты (Openpyxl):** Автоматическое выделение **ТОП-3 лучших товаров** мягким нежно-зелёным цветом (`#E2EFDA`) и **ТОП-3 худших товаров** мягким красным цветом (`#FCE4D6`). Колонки динамически адаптируются под длину текста.
5. **Тестирование без VPN:** Интегрирована поддержка SOCKS5-прокси внутри `aiogram`, что позволяет стабильно отправлять запросы к `api.telegram.org` и тестировать бота без конфликтов с локальными утилитами (например, Zapret).

## 📦 Настройка окружения
Для запуска проекта создайте файл `.env` в корневой директории:
```env
TELEGRAM_BOT_TOKEN=your_bot_token_here
ALIEXPRESS_API_KEY=your_api_key_here
DATABASE_URL=your_database_url
```

Подробная инструкция по установке и настройке находится в файле [SETUP.md](SETUP.md).

## ▶️ Запуск приложения

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Для запуска Telegram-бота выполните главную точку входа:
   ```bash
   python -m src.main
   ```
3. Для запуска интеграционных тестов:
   ```bash
   pytest -m tests.test_integration
   ```
